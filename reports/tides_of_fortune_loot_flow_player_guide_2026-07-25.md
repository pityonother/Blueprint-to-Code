# Tides of Fortune 漂流瓶奖池：玩家流程讲解版

生成日期：2026-07-25

这份报告是“玩家讲解版”，专门解释漂流瓶宝箱从选择奖池到生成最终物品的完整过程。它不会重复罗列全部 292 个物品。

完整物品、Blueprint 类名和每一个奖池条目仍保存在：

`tides_of_fortune_exact_loot_2026-07-25.md`

## 一句话结论

漂流瓶并不是直接从全部物品中随机抽取，而是按下面的层级逐步筛选：

```text
漂流瓶品质
→ 对应品质的埋藏宝箱
→ 最多进行 4 次奖励抽取
→ SetWeight 选择子奖池
→ EntryWeight 选择物品类别
→ item weight 选择具体物品
→ 数量 Min–Max 决定给多少
→ BP chance 决定实物还是蓝图
→ Entry 品质、宝箱倍率和服务器倍率参与最终装备品质生成
```

真正决定“抽到什么”的是三层权重：

```text
SetWeight → EntryWeight → item weight
```

数量、蓝图概率和品质都发生在具体物品路径已经被选中以后。

## 第一层：漂流瓶品质决定使用哪套宝箱

漂流瓶分为六档：

| 漂流瓶品质 | 宝箱开启等级 | 宝箱品质倍率 |
|---|---:|---:|
| Primitive（原始） | 1 | 2.0–4.0 |
| Ramshackle（简陋） | 15 | 2.0–4.0 |
| Apprentice（学徒） | 25 | 2.0–4.0 |
| Journeyman（优秀） | 35 | 2.0–4.0 |
| Mastercraft（大师） | 45 | 2.0–4.0 |
| Ascendant（传说） | 60 | 2.0–4.0 |

漂流瓶品质主要改变的是：

- 使用哪个埋藏宝箱类；
- 宝箱包含哪些候选 Item Set；
- 哪些武器、护甲、鞍具、建筑、资源和消耗品有机会出现；
- 各个子奖池的相对权重。

漂流瓶品质不直接代表：

- 最终装备一定与漂流瓶同名品质；
- 传说漂流瓶只会出现传说装备；
- Primitive 漂流瓶只能出现原始装备；
- 高品质漂流瓶拥有更高的宝箱品质倍率。

当前六档宝箱的 `MinQualityMultiplier` 和 `MaxQualityMultiplier` 都是 `2.0` 和 `4.0`。六档之间最明显的变化是奖池构成，不是把这个倍率逐档抬高。

## 第二层：开启等级只控制能不能开箱

`RequiredLevelToAccess` 是开启埋藏宝箱所需的玩家等级。

例如：

```text
Primitive：1 级
Ramshackle：15 级
Ascendant：60 级
```

这个参数只进行资格检查，不会提高或降低：

- 子奖池概率；
- 具体物品概率；
- 蓝图概率；
- 物品数量；
- 最终装备品质。

## 第三层：宝箱最多进行 4 次奖励抽取

宝箱基类当前确认：

```text
MaxItemSets = 4
```

六档宝箱的每个外层 Item Set 当前又设置为：

```text
MinNumItems = 1
MaxNumItems = 1
NumItemsPower = 1
```

可以把它理解为：

> 宝箱最多选择 4 个 Item Set；每选中一个 Item Set，就在该子奖池中进行一次物品条目抽取。

因此逻辑上最多进行 4 次物品选择，但不等于箱子中只能看见 4 个单体物品：

- 抽中资源后，一次选择可能生成 20–100 个资源；
- 抽中弹药后，一次选择可能生成 5–50 发弹药；
- 两次抽中相同的可堆叠物品时，进入箱子后可能合并成一个物品堆；
- 一次结构类结果可能生成 1–2 个同种结构物品。

当前资产明确确认的是“最多 4 次”。究竟什么情况下选择 1、2、3 或 4 个 Item Set，仍由没有完整恢复的原生逻辑决定，不能仅凭 `MaxItemSets = 4` 断言每箱固定抽 4 次。

## 第四层：SetWeight 决定选择哪个子奖池

`SetWeight` 是同一宝箱中各个子奖池的相对权重。

计算公式：

```text
某子奖池的单次占比
= 该子奖池 SetWeight ÷ 所有候选子奖池 SetWeight 总和
```

### Primitive 漂流瓶实例

Primitive 宝箱有六个外层候选：

| 子奖池 | SetWeight | 单次外层抽取占比 |
|---|---:|---:|
| Level 25 完整池 | 0.3 | 20.30% |
| 石制建筑池 | 0.05 | 3.38% |
| Level 35 完整池 | 1 | 67.68% |
| 温室建筑池 | 0.1 | 6.77% |
| Level 45 品质专用池 | 0.025 | 1.69% |
| Level 45 品质专用池第二入口 | 0.0025 | 0.17% |

总权重：

```text
0.3 + 0.05 + 1 + 0.1 + 0.025 + 0.0025
= 1.4775
```

所以 Level 25 完整池的单次占比是：

```text
0.3 ÷ 1.4775 ≈ 20.30%
```

必须注意：

- `SetWeight = 1` 不代表 100%；
- `SetWeight = 0.3` 不代表 30%；
- 权重 1 的相对机会约为权重 0.3 的 3.33 倍；
- 两个条目即使指向同一个子奖池，在外层仍然是两张独立配置的“彩票入口”。

## 第五层：EntryWeight 决定子奖池中的物品类别

假设刚才抽中了 Primitive 的 Level 25 完整池。

游戏仍然不会直接抽十字弩，而是先在下面这些类别中选择一个：

| Level 25 类别 | EntryWeight | 进入该池后的类别占比 |
|---|---:|---:|
| 可用建筑 | 0.4 | 6.45% |
| 有品质武器、工具和护甲 | 0.6 | 9.68% |
| 有品质鞍具 | 0.5 | 8.06% |
| 无品质武器、工具和护甲 | 0.8 | 12.90% |
| 大数量消耗品 | 1 | 16.13% |
| 小数量消耗品 | 0.9 | 14.52% |
| 资源 | 1 | 16.13% |
| 弹药 | 0.8 | 12.90% |
| 仅蓝图弹药 | 0.2 | 3.23% |

这些 EntryWeight 的总和是：

```text
0.4 + 0.6 + 0.5 + 0.8 + 1 + 0.9 + 1 + 0.8 + 0.2
= 6.2
```

所以“有品质武器、工具和护甲”的条件概率是：

```text
0.6 ÷ 6.2 ≈ 9.68%
```

这里的 9.68% 只表示：

> 已经进入 Level 25 完整池以后，抽中该物品类别的概率。

它不是整只漂流瓶 9.68%，也不是每一件装备各有 9.68%。

## 第六层：item weight 决定类别中的具体物品

抽中一个 Entry 后，游戏继续从该行列出的物品中选择一种。

### 没有单物品权重

Level 25 的“有品质武器、工具和护甲”包含 9 件物品，而且没有单独的 `ItemsWeights`：

- 十字弩；
- 金属镰刀；
- 金属矛；
- 手铐；
- 毛皮靴；
- 毛皮手套；
- 毛皮帽；
- 毛皮护腿；
- 毛皮胸甲。

当前报告按默认等权逻辑处理：

```text
每件物品条件概率 = 1 ÷ 9 ≈ 11.11%
```

### 存在单物品权重

Level 25 的“可用建筑”类别具有不同的 item weight：

| 物品 | item weight | 进入该类别后的条件占比 |
|---|---:|---:|
| 弩炮台 | 0.2 | 1.90% |
| 火炮 | 0.2 | 1.90% |
| 绊线报警陷阱 | 2 | 19.05% |
| 绊线麻醉陷阱 | 2 | 19.05% |
| 精炼炉 | 0.4 | 3.81% |
| 马桶 | 1 | 9.52% |
| 壁炉 | 0.6 | 5.71% |
| 树脂龙头 | 2 | 19.05% |
| 木制树屋平台 | 0.1 | 0.95% |
| 神器底座 | 2 | 19.05% |

该行的 item weight 总和是 10.5。

例如：

```text
弩炮台：0.2 ÷ 10.5 ≈ 1.90%
绊线报警陷阱：2 ÷ 10.5 ≈ 19.05%
```

所以报警陷阱在该类别中的相对机会是弩炮台的 10 倍。

## 第七层：数量 Min–Max 决定给多少

具体物品已经选中后，游戏才根据数量范围决定一次生成多少。

| 数量配置 | 玩家应该怎样理解 |
|---|---|
| 1–1 | 固定给 1 个 |
| 1–2 | 给 1 个或 2 个同种物品 |
| 5–30 | 给一叠 5–30 个 |
| 20–100 | 给一叠 20–100 个 |

例如资源行包含甲壳素、稀有花朵、稀有蘑菇、水泥和毛皮，数量是 `20–100`。

正确流程是：

```text
先从五种资源中选中一种，例如水泥
→ 再生成 20–100 个水泥
```

不是给 20–100 种资源，也不是把该行所有资源都给一遍。

## 第八层：BP chance 决定实物还是蓝图

具体物品路径被选中后，`BP chance` 才进行蓝图转换判定。

| BP chance | 结果 |
|---:|---|
| 0 | 固定给实物 |
| 0.1 | 10% 蓝图，90% 实物 |
| 0.2 | 20% 蓝图，80% 实物 |
| 0.5 | 50% 蓝图，50% 实物 |
| 1 | 固定给蓝图 |
| Force BP | 强制生成蓝图 |

因此 `BP chance = 0.1` 不是“整只漂流瓶有 10% 出蓝图”，而是：

```text
已经抽中该 Item Set
→ 已经抽中该 Entry
→ 已经抽中某件具体装备
→ 最后再以 10% 概率把这件装备转换成蓝图
```

同一物品可能在不同 Entry 中重复出现，并拥有不同的品质区间和 BP chance。因此计算一件物品的完整概率时，必须把所有路径合并。

## 第九层：装备品质最后计算

如果抽中的物品支持品质，最终品质生成至少受到这些输入影响：

```text
Entry 的 Min Quality / Max Quality
宝箱的 MinQualityMultiplier / MaxQualityMultiplier
服务器 SupplyCrateLootQualityMultiplier
原生物品属性生成与限制逻辑
```

例如 Level 25 池中的十字弩有两条不同路径：

### 有品质十字弩

```text
Entry 品质：1.8–3.84
BP chance：0.1
数量：1–1
```

这条路径会进入装备品质生成，并有 10% 条件概率转换成蓝图。

### 无品质十字弩

```text
Entry 品质：0–1
BP chance：0
数量：1–1
```

这条路径固定生成实物，通常接近基础装备路线。

`1.8–3.84` 不是装备等级，也不能直接与 `2.0–4.0` 相乘后映射成某个可见品质名称。当前 Blueprint 资产确认了这些输入范围，但最终装备属性点分配、品质名称、钳制和限制位于原生逻辑中，没有恢复出可靠的闭式公式。

## 完整算例：一次外层抽取如何得到十字弩

以下只计算 Primitive 宝箱中 Level 25 完整池的两条十字弩路径。

### 路径 A：有品质十字弩

```text
抽中 Level 25 完整池：
0.3 ÷ 1.4775 ≈ 20.3046%

抽中有品质装备类别：
0.6 ÷ 6.2 ≈ 9.6774%

从 9 件等权物品中抽中十字弩：
1 ÷ 9 ≈ 11.1111%
```

合并路径：

```text
20.3046% × 9.6774% × 11.1111%
≈ 0.2183%
```

该行的 BP chance 是 0.1，所以：

```text
有品质十字弩蓝图：
0.2183% × 10% ≈ 0.0218%

有品质十字弩实物：
0.2183% × 90% ≈ 0.1965%
```

### 路径 B：无品质十字弩

```text
20.3046%
×（0.8 ÷ 6.2）
×（1 ÷ 9）
≈ 0.2911%
```

该行 BP chance 是 0，因此这 0.2911% 全部是实物。

### 两条 Level 25 路径合并

| 结果 | 每次外层 Item Set 抽取概率 |
|---|---:|
| 十字弩蓝图 | 0.0218% |
| 十字弩实物 | 0.4876% |
| 任意形式十字弩 | 0.5094% |

这仍然不是整只 Primitive 漂流瓶的最终十字弩概率，因为：

- 宝箱最多选择 4 个 Item Set；
- 原生逻辑实际选择几个 Item Set 的分布尚未恢复；
- 十字弩还可能出现在其他子奖池；
- 同一物品可能通过不同品质行和重复奖池入口出现；
- 多次抽取是否重复以及最终堆叠方式会影响箱内表现。

## 六档漂流瓶的大方向

| 漂流瓶档位 | 奖池构成的主要变化 |
|---|---|
| Primitive | Level 25/35 完整池、石制/温室建筑，以及很低权重的 Level 45 品质池 |
| Ramshackle | 以 Level 45 完整池为主，并附带品质专用池 |
| Apprentice | 以 Level 60 完整池为主，附带金属、Tek 和 Level 60 品质池 |
| Journeyman | 主要进入洞穴 T1/T2/T4 护甲与武器，以及水下 T1 护甲池 |
| Mastercraft | 洞穴 T2、T4、水下 T1/T2；两个界面标记为 T3 的入口实际指向 T1 资产 |
| Ascendant | 洞穴 T1/T2/T3/T4 与水下 T1/T2/T3 全部存在 |

因此 Ascendant 漂流瓶仍包含 T1/T2 候选池，不等于只从最高阶装备中抽取。

## 六档宝箱逐个奖池说明

下面的“单次外层占比”表示：

> 宝箱进行一次 Item Set 选择时，进入该子奖池的概率。

它不是整只漂流瓶的最终概率，因为一个宝箱最多会进行 4 次 Item Set 选择。

物品示例均来自对应子奖池的实际候选列表，不是根据奖池名称猜测。为了让这一版可以阅读，每个池列出主要类别和有代表性的具体物品；全部物品仍可在完整技术报告中按同名子奖池查询。

#### Primitive 具体例子：为什么最常见的不是 Level 25

一次外层抽取中，Level 35 完整池占约 67.68%。假设进入该池后抽中资源行：

```text
Level 35 池：1 ÷ 1.4775 ≈ 67.68%
资源行：1 ÷ 5.2 ≈ 19.23%
6 种资源中抽中金属锭：1 ÷ 6 ≈ 16.67%
```

因此，通过这条路径得到一叠 `10–80` 个金属锭的单次外层概率约为：

```text
67.68% × 19.23% × 16.67% ≈ 2.1693%
```

这说明 Primitive 并不是主要在抽低级 Level 25 池；它最常进入的是包含中级装备、鞍具、资源和消耗品的 Level 35 完整池。

#### Mastercraft 具体例子：为什么会出现石镐蓝图

界面标记为 T3 的武器入口实际指向 T1 武器池，其单次外层占比约为：

```text
0.8 ÷ 5.6 ≈ 14.29%
```

T1 武器池的 EntryWeight 总和是：

```text
品质武器 1 + 无品质工具 0.8 + 弹药 1 = 2.8
```

因此通过这个异常入口得到石镐蓝图的单次外层概率约为：

```text
14.29% ×（1 ÷ 2.8）×（1 ÷ 6）× 50%
≈ 0.4252%
```

所以 Mastercraft 漂流瓶开出高品质石镐或石镐蓝图，在当前配置下并不矛盾：它来自标记为 T3、实际指向 T1 的错误路由。

### 高阶洞穴武器池的共同读法

T2、T3、T4 武器池通常有三行：

```text
品质武器：EntryWeight 1，品质 3.6–7.2，BP 50%
无品质武器或爆炸物：EntryWeight 0.3，品质 0–1，BP 0
弹药：EntryWeight 1，数量 4–20，BP 0
```

所以进入这种武器池以后：

```text
品质武器行：1 ÷ 2.3 ≈ 43.48%
无品质爆炸物行：0.3 ÷ 2.3 ≈ 13.04%
弹药行：1 ÷ 2.3 ≈ 43.48%
```

也就是说，进入一个“高阶武器池”仍有约 43.48% 的机会只抽到一叠弹药。池名写 T4 Weapons，并不代表每次都给一把 T4 武器。

T1 武器池的无品质行权重是 `0.8`，所以内部比例是：

```text
品质武器：1 ÷ 2.8 ≈ 35.71%
无品质工具：0.8 ÷ 2.8 ≈ 28.57%
弹药：1 ÷ 2.8 ≈ 35.71%
```

## 参数速查表

| 报告参数 | 影响哪一步 | 不代表什么 |
|---|---|---|
| 漂流瓶品质 | 选择整套宝箱和奖池 | 不直接保证最终装备品质 |
| 开箱等级 | 玩家能否开启宝箱 | 不影响掉率和装备属性 |
| MaxItemSets | 最多选择多少个子奖池 | 不代表固定抽满 |
| Item Set 行数 | 报告中配置了多少个候选池 | 不代表实际奖励数量 |
| SetWeight | 选择哪个子奖池 | 不是直接百分比 |
| EntryWeight | 选择子奖池中的哪个类别 | 不直接决定具体物品 |
| item weight | 选择类别中的哪件物品 | 不影响蓝图和品质 |
| 数量 Min–Max | 选中后给多少个 | 不影响抽中概率 |
| BP chance | 实物转换为蓝图的条件概率 | 不是整箱蓝图概率 |
| Force BP | 强制生成蓝图 | 不增加物品出现概率 |
| Entry 品质 | 装备品质生成的输入范围 | 不是可见品质等级 |
| 宝箱品质倍率 | 参与最终装备品质生成 | 不改变奖池选择概率 |
| 去重物品类 | 报告统计的候选物品种类 | 不是单箱物品数量 |
| 精确池路径 | 用于核对 DevKit 资产 | 对掉落没有额外加成 |

## 当前已经确认与仍未确认的边界

已经从当前本机 ARK DevKit 资产确认：

- 六档漂流瓶对应六套宝箱；
- 六档开箱等级；
- 六档宝箱品质倍率均为 2.0–4.0；
- `MaxItemSets = 4`；
- 每个外层 Item Set 的 `MinNumItems = MaxNumItems = 1`；
- 六档的 SetWeight；
- 子池中的 EntryWeight、数量、品质区间和 BP chance；
- 292 个不同物品类及对应中文名称。

尚未从 Blueprint 资产完整确认：

- 宝箱最终选择 1、2、3 或 4 个 Item Set 的精确概率分布；
- 多次外层选择之间完整的重复处理算法；
- Entry 品质、宝箱倍率和服务器倍率转换为最终装备属性的原生闭式公式；
- 单件物品在整只宝箱中的最终累计概率。

因此技术清单可以精确回答“某件物品存在于哪条路径、每层权重是多少”，但要生成真正可靠的“每开一个瓶子有多少概率得到某物”的最终概率表，还需要补充原生抽取行为或进行足量游戏内统计测试。
