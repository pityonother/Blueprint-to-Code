# 授权与分发策略

## 状态

已确认，2026-07-27。

## 决定

本项目当前不授予开源许可证，仓库根目录因此有意不提供 `LICENSE` 文件。版权由项目作者保留。

项目作者不需要从自己获得使用许可，可以继续使用、修改、复制和发布自己的代码。对第三方而言，
仓库公开可见不等于获得开源授权；除托管平台条款提供的必要权限外，第三方不能据此假定其获得了
复制、修改、再分发或制作衍生作品的许可。

GitHub 的[仓库许可说明](https://docs.github.com/zh/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository)
同样说明，项目没有许可证时适用默认版权规则，作者保留源代码权利。该链接仅用于说明仓库行为，
不构成法律意见。

## 分发边界

- ARK DLL/PDB、ARK DevKit 或游戏资产不得纳入仓库和发布包。
- Ghidra workspace、完整 proprietary 反编译输出和未脱敏本地 evidence 不得公开分发。
- 第三方依赖和可选工具继续受其各自许可证约束，不因本项目策略而重新授权。
- 接受外部贡献或向第三方授予复用权前，需要由作者另行给出明确书面授权。

## 将来如何变更

如果作者以后决定把项目开放为开源项目，应明确选择一份标准许可证，在仓库根目录添加对应
`LICENSE` 文件，并同步更新本策略、README 和发布检查。该变更必须由作者明确作出，不由自动化
工具推断。
