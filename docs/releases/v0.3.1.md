# Blueprint to Code v0.3.1 — Windows Portable Engineering Preview

## 发布定位

v0.3.1 在保留可审查源码合同的同时，新增面向普通 Windows 用户的便携包：

```text
RELEASE_TYPE=ENGINEERING_PREVIEW_SOURCE_AND_WINDOWS_PORTABLE
```

本版本会作为正式 GitHub Release 发布。v0.3.0 的 tag 与 source-only 合同保持不变；
不会移动或重写已发布的历史标签。

## 普通用户应该下载哪个文件

请下载：

```text
BlueprintToCode-v0.3.1-windows-x64-portable.zip
```

同一 Release 还提供对应的 `.zip.sha256`。不要下载 `Source code (zip)` 或
`Source code (tar.gz)` 来直接使用；它们是 GitHub 自动生成的开发者源码归档，不含
预构建网页和内置运行时。

## 解压即用

1. 把 ZIP 完整解压到普通、可写的目录；不要在压缩包预览窗口内运行；
2. 双击 `START_HERE.bat`；
3. 浏览器会打开 `http://127.0.0.1:8765/`；
4. 使用期间保持命令窗口开启。

便携包自带预构建的 `dist/` 和经过来源核验的 Python 3.13.13 Windows x64
embeddable runtime，因此不需要安装 Python，也不需要安装 Node.js。排错入口是
`DIAGNOSE.bat`，简明说明位于 `QUICK_START_zh.txt`。

## ARK DevKit 边界

打开网页和本地服务不要求 ARK DevKit。要从用户自己的真实 `.uasset` / `.uexp`
读取新证据，用户仍需在自己的 Windows 电脑合法安装 ARK DevKit。工具会先读取
Epic Games Launcher 清单自动发现路径；自动发现失败时，按使用手册配置
`devkit_content_root.txt`。

ARK DevKit 和游戏资产不能随项目再分发，因此不能打进便携包。

## 完整性与供应链

- 外部 `.zip.sha256` 绑定整个下载文件的 SHA-256；
- 包内 `SHA256SUMS.txt` 绑定除自身外的每个文件；
- `PACKAGE_MANIFEST.json` 绑定版本、Git commit、平台、文件数与运行时来源；
- 构建时核对 python.org 上游 ZIP 的 SHA-256、34 个文件的完整清单和内容；
- 发布前在全新解压目录实际运行用户入口 `START_HERE.bat`，并检查 HTTP 健康状态。

## 明确不包含的内容

- 不包含 ARK 数据
- 不包含 DevKit
- 不包含 ARK/ShooterGame DLL/PDB；便携包仅包含经来源核验、启动所需的
  Python runtime DLL/PYD
- 不包含 Capture/Evidence DB
- 不包含真实 runtime observations
- 不包含 Harvest 数据库、Knowledge Base、Native Evidence 或 Ghidra workspace
- 不包含构建电脑的 DevKit 路径、用户目录、凭据或本地日志

用户第一次启动时，本机还没有自己的 Capture 或分析结果属于正常状态；开始分析后，
输出会写入解压目录内的 `captures/`、`analysis/` 和 `logs/`。

## 已知限制

- 这是 Engineering Preview，不是完整 Blueprint decompiler，也不会恢复开发者的
  原始 C++；
- 便携 ZIP 当前未做 Authenticode 代码签名，Windows 可能显示安全提示；
- 默认服务只监听本机 `127.0.0.1:8765`；
- confirmed interpretation 必须保留 Evidence trace，缺失来源的内容继续标为 gap、
  `HEURISTIC`、`NOT_RECOVERED`、`SOURCE_NOT_AVAILABLE` 或 `AMBIGUOUS`；
- ARK KB 继续保持 `mode=shadow`、`defaultQuerySource=legacy`、
  `cutoverEligible=false`，本版本不切换 live KB pointer；
- 无 ARK DevKit 的电脑可以打开应用，但不能从新的 proprietary ARK 资产生成证据。
