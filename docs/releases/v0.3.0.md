# Blueprint to Code v0.3.0 — Engineering Foundation Milestone

## 本次发布是什么

Blueprint to Code v0.3.0 是一个 Engineering Foundation Milestone：它交付工程
基础设施、证据优先分析能力和 prepublication 增量验证的稳定软件 Release。

它不是 vNext cutover，不是完整 Blueprint decompiler，不是原始 C++ 恢复工具，
也不是 ARK 数据发布包。软件达到稳定发布合同不表示 ARK Knowledge Base 已经达到
生产切换条件。

## 主要能力

- immutable-v2 Snapshot 与原子 `current.json` pointer；
- 发布前密封门禁、previous-snapshot identity binding 和 fail-closed cutover 合同；
- typed registration，以及 Role / Domain foundations；
- Gold review、签名 receipt 和 registry foundations；
- reparse-safe whole-tree staging 与 additive quarantine；
- exact Source Manifest binding 和 strict additive plan；
- base-bound Delta Receipt v3，并在真实 prepublication 检查中得到
  `baseBindingVerified=true`；
- production `QUERY_SNAPSHOT` cache invalidation；
- worker-owned transaction、external marker 与 crash recovery。

Role、Domain 和 Projection foundations 不等于生产 Backend 已完成。当前仍未完成：

- Role Backend；
- Domain Backend；
- Projection Backend；
- production narrow gates；
- incremental publisher；
- Gold thresholds；
- burn-in；
- cutover。
